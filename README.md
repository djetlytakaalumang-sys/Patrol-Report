# 🛡️ Patrol Report System

Sistem laporan harian patroli keamanan berbasis web — ringan, tanpa backend, langsung jalan di browser.

## ✨ Fitur
- Input laporan harian (personil masuk, patroli, off, report)
- Generate teks laporan otomatis
- Kirim via WhatsApp
- Manajemen data personil
- Arsip laporan
- Pengaturan profil & unit

## 🚀 Deploy

### Vercel (Recommended)
1. Fork / push repo ini ke GitHub
2. Buka [vercel.com](https://vercel.com) → **New Project**
3. Import repo ini
4. Klik **Deploy** — selesai!

### GitHub Pages
1. Push repo ke GitHub
2. Buka **Settings** → **Pages**
3. Source: pilih branch `main`, folder `/ (root)`
4. Save → akses di `https://username.github.io/nama-repo`

## 💾 Penyimpanan Data
Semua data tersimpan di **localStorage** browser (tidak perlu server/database).

## 🛠️ Teknologi
- HTML5 / CSS3 / JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts (Plus Jakarta Sans, JetBrains Mono)
- Tidak ada dependensi backend
